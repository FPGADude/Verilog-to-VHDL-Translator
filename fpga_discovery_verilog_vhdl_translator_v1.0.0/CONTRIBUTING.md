# Contributing

Thanks for your interest in the FPGA Discovery Verilog → VHDL Translator.

Bug reports and reproducible translation cases are especially useful. When reporting a translator problem, please include:

1. the smallest Verilog example that reproduces it;
2. the generated VHDL if translation completes;
3. the Project Translation Report;
4. Vivado error/warning text when applicable;
5. Vivado version and target FPGA part.

Please check `SUPPORTED_VERILOG.md` before filing a language-support bug. A construct outside the documented v1.0 subset may be considered a feature request rather than a defect.

Contributions are subject to the repository's `LICENSE`. Submitting a contribution does not change the license terms of the project.
